# Meu Vício - Catálogo de calçados

> Catálogo digital para apresentar produtos, organizar o estoque por numeração e direcionar o atendimento para o WhatsApp.

[![Ver demonstração online](https://img.shields.io/badge/demo-online-6f4f28?style=flat-square)](https://meu-vicio-catalogo.vercel.app/)

![Catálogo Meu Vício](https://meu-vicio-catalogo.vercel.app/products/personalizacao-2.jpg)

## Visão geral

O Meu Vício é um projeto próprio de catálogo de calçados criado para aproximar a vitrine digital do atendimento da loja. A pessoa visitante pode explorar os produtos, filtrar por categoria e tamanho, montar uma sacola e continuar o atendimento pelo WhatsApp.

O projeto está em evolução e possui uma estrutura preparada para catálogo, administração de produtos, imagens, estoque e atendimento.

## Funcionalidades

- Catálogo de produtos com busca por modelo ou cor.
- Filtros por categoria, faixa de numeração e público.
- Controle de disponibilidade por numeração.
- Favoritos e sacola de produtos.
- Encaminhamento da seleção para atendimento via WhatsApp.
- Área institucional com destaques e produtos personalizados.
- Painel administrativo para produtos, imagens e informações do catálogo.
- Interface responsiva para computadores e celulares.

## Executar localmente

Requisitos: Node.js 22.13 ou superior.

1. Instale as dependências com npm install.
2. Configure as variáveis de ambiente a partir do arquivo .env.example.
3. Inicie o ambiente de desenvolvimento com npm run dev.
